# Metallic Sample Pack
This is a silly sample pack created by hitting random stuff in my kitchen together.
This was recorded on a Shure MV7 and Focusrite Scarlett 2i2 connected to my phone.
This was recorded when I was doing laundry so there is quite a bit of background noise.
The only processing on these is a 0dB limiter and some leveling.

Not the highest quality sounds but maybe can be used for some ear candy or foley.
Enjoy!
